# 🌦️ Weather App

A responsive weather application built with HTML, CSS, and JavaScript using the Open-Meteo API.

##  Live Demo

https://abdo1454.github.io/weather-app/

##  Features

- Search weather by city
- Current weather conditions
- 7-day forecast
- Hourly forecast
- Unit conversion
- Responsive design

##  Technologies

- HTML5
- CSS3
- JavaScript
- Open-Meteo API

##  What I Learned

- API Integration
- Async/Await
- Fetch API
- Dynamic DOM Rendering
- Error Handling
